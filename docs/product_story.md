# Product and operations story

## Target users

- Urban commuters comparing safe and practical travel options
- GIS and mobility operators maintaining spatial knowledge
- Service teams answering policy and facility questions

## Core scenarios

1. Retrieve traffic policy, safety and facility guidance with source citations.
2. Route location, POI, weather and navigation requests to map tools.
3. Capture negative feedback and convert it into corpus, routing or retrieval improvements.

## Iteration loop

`Query log -> failure categorization -> corpus update or rule adjustment -> offline evaluation -> controlled release`

The evaluation set separates retrieval, routing and citation quality so a metric change can be traced to a specific component rather than hidden behind one overall answer score.
